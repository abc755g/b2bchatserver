# firstVDS: регистрация и подготовка сервера

## Регистрация

1. Перейдите по ссылке: `https://firstvds.ru/?from=519065`.
2. Используйте промокод `648519065` для скидки 25% на первый месяц.
3. Создайте аккаунт.
4. Подтвердите email и телефон (если запрошено).

## Создание сервера

1. Создайте VDS/VPS с Ubuntu 22.04 LTS (или 20.04 LTS).
2. Выберите тариф не ниже требований из основного [README](../../README.md#требования).
3. Добавьте SSH-ключ или задайте пароль для `root`.

## Что сохранить после создания

- Внешний IPv4-адрес сервера.
- Логин `root`.
- Пароль или приватный ключ для SSH.

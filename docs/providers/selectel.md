# Selectel: регистрация и подготовка сервера

## Регистрация

1. Перейдите по ссылке: `https://selectel.ru/?ref_code=beeabc92bf`.
2. Создайте аккаунт.
3. Активируйте проект/облако и пополните баланс (если требуется для запуска).

## Создание сервера

1. Создайте облачный сервер с Ubuntu 22.04 LTS (или 20.04 LTS).
2. Выберите тариф не ниже требований из основного [README](../../README.md#требования).
3. Добавьте SSH-ключ при создании инстанса или задайте пароль.

## Что сохранить после создания

- Публичный IPv4-адрес сервера.
- Данные доступа для SSH-подключения.

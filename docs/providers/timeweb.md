# Timeweb Cloud: регистрация и подготовка сервера

## Регистрация

1. Перейдите по ссылке: `https://timeweb.cloud/?i=141497`.
2. Создайте аккаунт и завершите базовую верификацию.

## Создание сервера

1. В панели откройте раздел создания облачного сервера.
2. Выберите образ Ubuntu 22.04 LTS (или 20.04 LTS).
3. Выберите тариф не ниже требований из основного [README](../../README.md#требования).
4. Подключите SSH-ключ или задайте пароль администратора.

## Что проверить после создания

- Серверу назначен публичный IPv4-адрес.
- Данные для SSH-подключения сохранены.
